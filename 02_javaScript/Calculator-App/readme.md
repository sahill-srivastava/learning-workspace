# Simple Calculator App

A straightforward calculator built with HTML, CSS, and JavaScript. It supports mouse clicks and keyboard input for seamless arithmetic calculations.

## 📸 Screenshot

![Calculator Screenshot](/calc-screenshot.png)

## 🧠 Features

- Basic arithmetic operations: addition, subtraction, multiplication, division
- Keyboard input support (numbers, operators, Enter for equals, Backspace for delete, Escape for clear)
- Clear (`AC`) and Delete (`DEL`) buttons
- Real-time input and result display

## 🚀 Tech Stack

- HTML  
- CSS  
- JavaScript

## ⚙️ How to Run

1. Clone or download this repository  
2. Open the `index.html` file in your favorite web browser  
3. Use the buttons or keyboard to perform calculations

## 💡 Usage Instructions

- Click the buttons or use your keyboard to input numbers and operators  
- Press `Enter` or `=` to calculate the result  
- Use `DEL` or Backspace to delete the last character  
- Use `AC` or Escape to clear the input field
