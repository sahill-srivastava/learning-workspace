# Book Library API

A beginner level backend learning project on node.js, express.js, mongodb, mongoose primarily focused on how we manage books apis on backend and handled operations such as get, post, patch, put and delete request.

## API Endpoint Used
- CREATE : creating books
- GET: get books
- GET/:id : get single book
- PATCH/:id : update book
- PUT/:id : replcae book
- DELETE/:id : delete book


## Learning

- Creating & handle model
- Creating & handle routes and controller
- Managing Endpoint operations
