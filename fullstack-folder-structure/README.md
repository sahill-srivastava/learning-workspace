# FULLSTACK FOLDER STRUCTURE

Folder structure is categorised into two parts:
- Frontend or client
- Backend or server

---
### CLIENT


It consists frontend tools/libs/packages/source code such as:

- React
- Tailwind
- Vite
- package.json
- node_modules
- Others


---
### SERVER

It consists backend tools/libs/packages/source code + database logic such as:

- Express
- Mongodb
- Mongoose
- package.json
- node_modules
- Others
